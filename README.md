**Lightweight SSH/SFTP File Manager & Code Editor**

> 💡 **Why AunSSH Mini?**
> Modern IDEs are powerful — but often heavy, slow to launch, and unnecessary for quick server edits.
> Sometimes you just need to:
>
> * Connect to a server
> * Open a file
> * Make a quick change
> * Save and move on
>
> That’s exactly why **AunSSH Mini** exists.
> A lightweight, fast, and minimal SSH/SFTP editor built for speed and simplicity — no bloated setup, no long loading times, no distractions.

Manage remote files and edit code directly on your server with a clean and efficient interface designed for everyday work.


## ✨ Features

| Feature                | Description                                                     |
| ---------------------- | --------------------------------------------------------------- |
| 📂 **File Manager**    | Browse, create, rename, move, and delete remote files & folders |
| ✏️ **Code Editor**     | Edit files directly on your server    |
| 🔐 **Authentication**  | Supports both password and private key (SSH Key) login          |
| 🎨 **Dark Theme**      | Clean dark interface designed for comfortable long sessions     |
| 📰 **News Banner**     | Receive announcements and updates directly from aunssh.com      |
| ⚡ **Lightweight**      | Minimal resource usage with fast startup performance            |
| 🖥️ **Cross-Platform** | Available for both Windows and Linux                            |

### System Requirements

* Windows 10/11 or Linux (Ubuntu/Debian-based)
* No Python installation required
* Standalone executable — ready to run

## 🚀 Quick Start

### Windows

1. Download `AunSSH_Mini-windows.exe`
2. Double-click to launch
3. Enter your server credentials
4. Connect and start editing instantly

### Linux

```bash
chmod +x aunssh-mini-linux
./aunssh-mini-linux
```
